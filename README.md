# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML;
- CSS;
- Git;
- GitHub.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.


## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.


### БЭМ-именование
Все основные компоненты названы по методологии БЭМ:
- **Блоки:** `site-header`, `site-nav`, `hero`, `section`, `product-card`, `products-grid`, `order-form`, `order-dialog`, `button`, `site-footer`, `up-button`.
- **Элементы:** `site-nav__link`, `product-card__title`, `product-card__price`, `order-form__input`, `site-footer__text`.
- **Модификаторы:** `site-nav__link--active`, `product-card--featured`, `product-card--discount`, `button--primary`, `button--secondary`.

### Позиционирование
- `position: sticky` — верхняя шапка сайта.
- `position: relative` — карточка товара (контейнер).
- `position: absolute` — бейдж «Скидка» в карточке товара.
- `position: fixed` — кнопка «Наверх» в правом нижнем углу.
- `z-index` — для шапки (100), модального окна (200), кнопки «Наверх» (50).

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню (`.site-nav__list`);
- Flexbox для внутренней структуры карточек товаров (`.product-card`);
- CSS Grid для сетки карточек (`.products-grid` → 3 колонки);
- CSS Grid для страницы каталога с фильтрами и списком товаров (`.catalog-layout` → 260px + 1fr).

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:
- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта;
- `success-message` — сообщение об успешной отправке.

## Самостоятельные доработки

В рамках подготовки КР №1 реализованы дополнительные элементы:
- **Фиксированная кнопка «Наверх»** (`position: fixed`) для быстрого возврата к началу страницы.
- **Sticky-фильтр каталога** (`position: sticky`) — блок фильтров остается на экране при прокрутке.
- **Варианты карточек через БЭМ-модификаторы** — карточка со скидкой (`product-card--discount`) и бейджем (`product-card__badge`, `position: absolute`).
- **Дополнительные состояния интерфейса** — `:active` для кнопок, `:hover` с подъемом для карточек, `:focus-within` для доступности.
